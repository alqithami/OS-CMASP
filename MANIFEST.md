# Artifact manifest

- `manuscript/`: LaTeX manuscript source.
- `artifacts/reference/`: reference PDF from the current draft package.
- `src/os_cmasp/`: Python source.
- `tests/`: contract tests.
- `data/templates/`: replay schemas/templates.
- `configs/`: manifest templates.
- `docs/`: repository protocol, pre-run lock, and experiment protocol.
- `.github/`: CI, paper build, release workflow, and templates.
